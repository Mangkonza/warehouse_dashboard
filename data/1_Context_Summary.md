# สรุปบริบทและโครงสร้างข้อมูลเชิงลึก (In-depth Context & Data Structure)

จากการวิเคราะห์ไฟล์ Excel ทั้งหมดในระดับโครงสร้าง (รวมถึง Sub-headers ที่ถูก Merge Cells ไว้) พบว่าข้อมูลเป็น **"รายงานผลการดำเนินงานด้านงานวิจัยและวิชาการ"** ของมหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตกำแพงแสน (คณะวิศวกรรมศาสตร์) 

เพื่อให้การทำ Data Warehouse และ ETL มีความสมบูรณ์แบบ 100% ผมได้เจาะลึกโครงสร้างคอลัมน์ทั้งหมดแบบ Nested (คอลัมน์หลัก และคอลัมน์ย่อย) ซึ่งแบ่งข้อมูลออกเป็น 6 โดเมนหลัก ดังนี้:

---

## 1. โครงการวิจัย (Research Projects)
*ไฟล์: `โครงการวิจัย 2568.xlsx` และไฟล์ "เรื่องเพื่อทราบ..." Sheet 1*

**โครงสร้างคอลัมน์:**
- **ลำดับที่** / **รหัสโครงการ** / **ชื่อโครงการ**
- **หัวหน้าโครงการ** / **ผู้ร่วมวิจัย** / **หน่วยงานรับผิดชอบ**
- **ความร่วมมือ:** แบ่งย่อยเป็น 1) `ในประเทศ` 2) `ต่างประเทศ`
- **ลักษณะโครงการ:** แบ่งย่อยเป็น 1) `สร้างความเข้มแข็ง` 2) `สอดคล้องกับนโยบาย`
- **งบประมาณ:** แบ่งย่อยอย่างชัดเจนเป็น 1) `ภายใน` (งบมหาลัย/คณะ) 2) `ภายนอก` (งบจากหน่วยงานอื่น)
- **แหล่งทุนวิจัย**
- **ระยะเวลาการดำเนินงาน:** `ระยะเวลาเริ่มดำเนินการ` / `ระยะเวลาสิ้นสุดการดำเนินการ`
- **การบูรณาการ:** แบ่งย่อยเป็น 1) `การนำความรู้จากการสอนรายวิชา` 2) `นำวิจัยมาใช้การเรียนการสอน` 3) `การบริการวิชาการ/ชื่อโครงการ`
- **ระดับ TRL** (Technology Readiness Level) / **หมายเหตุ**

---

## 2. โครงการพัฒนาวิชาการ (Academic Development)
*ไฟล์: `โครงการพัฒนาวิชาการ 2568.xlsx` และไฟล์ "เรื่องเพื่อทราบ..." Sheet 2*

**โครงสร้างคอลัมน์:**
- **ลำดับที่** / **ชื่อโครงการ** / **หัวหน้าโครงการ**
- **ผู้ร่วมโครงการ:** แบ่งย่อยเป็น 1) `ภายใน` 2) `ภายนอก`
- **หน่วยงานดำเนินการ**
- **ผู้ขอรับบริการ:** แบ่งย่อยเป็น 1) `ครั้งแรก` 2) `มากกว่า 1 ครั้ง`
- **งบประมาณ (ยอดรวม)**
- **การจัดสรรงบประมาณ (แตกย่อย):** 1) `ค่าอำนวยการ 15%` 2) `คณะ 5%` 3) `ภาควิชา 5%` 4) `มก. 5%`
- **บูรณาการการใช้ประโยชน์:** 1) `โครงการวิจัย` 2) `สิทธิบัตร/อนุสิทธิบัตร`
- **ลักษณะโครงการ:** 1) `สอดคล้องกับนโยบายชาติ` 2) `เพิ่มมูลค่า`
- **ระยะเวลาดำเนินการ:** 1) `เริ่มต้น` 2) `สิ้นสุด`
- **วันที่นำไปบูรณาการ:** 1) `เริ่มต้น` 2) `สิ้นสุด`
- **ระเบียนโครงการ** / **สถานะโครงการ** / **หมายเหตุ**

---

## 3. งานบริการวิชาการ (Academic Services)
*ไฟล์: `งานบริการวิชาการ 2568.xlsx` และไฟล์ "เรื่องเพื่อทราบ..." Sheet 3*

**โครงสร้างคอลัมน์:**
- **ลำดับที่** / **ชื่อเรื่อง/โครงการ** / **หน่วยงานผู้จัด/หน่วยงานร่วม**
- **ลักษณะงานบริการ (Checkmarks แบบติ๊กถูก):**
  1) `สอน` 2) `สอบ` 3) `เป็นกรรมการ` 4) `ประเมิน` 5) `ที่ปรึกษา` 6) `วิทยากร`
- **ผู้ดำเนินการ** / **ภาควิชา**
- **ระยะเวลาดำเนินการ** / **จำนวนผู้เข้าร่วม** / **หมายเหตุ**

---

## 4. ผลงานทางวิชาการ (Academic Publications)
*ไฟล์: `ผลงานทางวิชาการ 2568.xlsx` และไฟล์ "เรื่องเพื่อทราบ..." Sheet 4*

**โครงสร้างคอลัมน์:**
- **ลำดับที่** / **ชื่อผลงานทางวิชาการ** / **ชนิดของผลงาน** / **ระดับ (ชาติ/นานาชาติ)**
- **จำนวนเงินสนับสนุน**
- **เจ้าของผลงาน**
- **ผู้ร่วม (นักวิจัยร่วม):** แบ่งย่อยเป็น 1) `ต่างชาติ` 2) `ภายในประเทศ`
- **สังกัดภาควิชา/สาขาวิชา**
- **รายละเอียดการตีพิมพ์:** `รายละเอียดวารสาร/การประชุม`, `Volume`, `Issue`, `Page start`, `Page end`
- **หมายเหตุ**

---

## 5. งานทรัพย์สินทางปัญญา (Intellectual Property)
*ไฟล์: `งานทรัพสินทางปัญญา 2568.xlsx` และไฟล์ "เรื่องเพื่อทราบ..." Sheet 5*

**โครงสร้างคอลัมน์:**
- **ลำดับที่** / **เรื่อง (ชื่อผลงาน)** / **ผู้ประดิษฐ์** / **สังกัด**
- **ประเภททรัพย์สินทางปัญญา:** 1) `อนุสิทธิบัตร` 2) `สิทธิบัตร` (เช็คจากการทำเครื่องหมายในช่อง)
- **ขั้นตอนดำเนินการ:** 1) `วันที่ยื่นคำขอ` 2) `เลขที่คำขอ`
- **ได้รับความคุ้มครอง:** 1) `เลขที่` 2) `ระยะเวลาความคุ้มครอง`
- **คณะฯ สนับสนุน (จำนวนเงิน)** / **หมายเหตุ**

---

## 6. รายงานผลตัวชี้วัด (KPI Reports)
*ไฟล์: `หน่วยวิจัยและนวัตกรรม-แบบรายงานผลตัวชี้ว.xlsx`*

**โครงสร้างคอลัมน์:**
- **เป้าหมายระดับบน:** `ยุทธศาสตร์ (Strategy)` / `โครงการ/กิจกรรม` / `ตัวชี้วัด` / `คำอธิบายตัวชี้วัด`
- **รายละเอียดเป้าหมาย:** `รอบการเก็บข้อมูล` (เช่น ปีการศึกษา) / `หน่วยนับ` (เช่น ร้อยละ, หลักสูตร) / `ค่าเป้าหมาย ปีงบประมาณ 2569`
- **การประเมินผล:** `ผลการดำเนินงาน (ต.ค.68 - มี.ค.69)` / `หลักฐานรอบ 6 เดือน`
- **ข้อมูลผู้จัดทำ:** `ผู้รายงานข้อมูล` / `หมายเหตุ`

## 🚧 ปัญหาและจุดที่ต้องเตรียมตัวสำหรับการทำ ETL (Data Cleansing) แบบเจาะลึก
จากการแกะโครงสร้างลึกถึงระดับ Row ย่อย พบปัญหาที่ต้องเขียน Script Python (Pandas) หรือ dbt ในการทำ Data Cleansing ให้เนี้ยบดังนี้:

1. **Header แบบ Multi-index (Merged Cells ลึก 3-4 ชั้น):** 
   - ตัวอย่างใน "โครงการพัฒนาวิชาการ" มีหัวตารางหลักชื่อ "ผู้ร่วมโครงการ" และมีหัวตารางย่อยเป็น "ภายใน" / "ภายนอก" ซ้อนอยู่ข้างใต้ ทำให้ตอนดึงข้อมูลเข้า Database ต้องทำ `ffill()` (Forward Fill) ตรง Header และยุบรวม (Flatten) ชื่อคอลัมน์ให้เป็น `ผู้ร่วมโครงการ_ภายใน`, `ผู้ร่วมโครงการ_ภายนอก` ถึงจะเอาเข้า SQL ได้
2. **คอลัมน์ประเภท Checkmark (ติ๊กถูก):**
   - งานบริการวิชาการ มีการใช้ตัวอักษรพิเศษ (เช่น `ü`) ในคอลัมน์ 'สอน', 'สอบ', 'ประเมิน' ตอนทำ ETL จะต้องเขียน Script เปลี่ยนสัญลักษณ์เหล่านี้ให้กลายเป็น Boolean (`True/False` หรือ `1/0`) ทั้งหมด
3. **การเก็บข้อมูลหลายชื่อในช่องเดียว (Non-Atomic Values):**
   - ช่อง "ผู้ร่วมวิจัย" มีการพิมพ์รายชื่อคนหลายคนต่อกัน (เช่น `ผศ.ดร.ก, ผศ.ดร.ข, นาย ค.`) ต้องใช้คำสั่ง Split string ด้วยลูกน้ำ หรือช่องว่าง เพื่อแตกเป็น List หรือแตกเข้าตาราง Mapping `Dim_Researcher` (Many-to-Many Relationship)
4. **รูปแบบวันที่ที่ไม่เป็นมาตรฐาน:**
   - คอลัมน์ระยะเวลาดำเนินการ บางช่องพิมพ์ว่า `12 เดือน` บางช่องระบุวันที่ `2568-11-01` ซึ่งตอนเข้า Data Warehouse (เช่น BigQuery) ต้องทำการ Format และ Extract เป็น `Start_Date`, `End_Date` และ `Duration_Months` ให้เป็น Standard Date (`YYYY-MM-DD`)
